# STEP — SRM Talent Empowerment Program

Small Java project with weekly activities implementing and testing a simple `Account` class and related exceptions.

## Structure

- `week01/` — early activities and basic `Account` implementations.
- `week02/` — enhanced account behaviours and exception handling.

Each `activityNN` directory contains an `Account.java` implementation and, where provided, a test harness such as `TestAccount.java` or `TestAccountEnhanced.java`.

## Notes

- Files are organized by week and activity for incremental learning.
